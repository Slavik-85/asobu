Powerful underneath, simple on top

All the control you'd want from a power-user launcher, with none of it shoved in your face.

Isolated instances

Every setup keeps its own worlds, mods and config. Break one and the rest carry on happily.

Java, handled

Asobu installs the exact runtime each Minecraft version asks for. Java 8 or Java 25 — you'll never be asked.

Straight from Mojang

Game files, libraries and assets download direct from official servers and are checksum-verified. Nothing is proxied through us.

Mods on a switch

See every jar with its name, author and size. Flip one off without renaming files by hand.

Crashes, explained

Every session's output is kept. When something breaks, the log is one click away instead of buried in a folder.

Portable mode

Drop a marker file next to the exe and the whole launcher lives on your USB stick instead of AppData.

How signing in works

Asobu never sees your password. Sign-in happens with Microsoft directly, in your own browser.

  1. Your browser opens, not ours Asobu hands you off to Microsoft's official sign-in page using OAuth 2.0 with PKCE. Your credentials are typed into Microsoft's page, never into Asobu.
  2. Microsoft vouches for you Microsoft returns a token, which is exchanged with Xbox Live and then Minecraft services to confirm you own the game.
  3. The token stays on your machine Your refresh token is kept in Windows Credential Manager, encrypted by the operating system. It is never written to a plain file and never sent anywhere except Microsoft and Mojang.

Asobu has no servers. There is no Asobu account, no telemetry and no analytics. Nothing about you leaves your computer except the requests you'd make anyway — to Microsoft to sign in, and to Mojang to download the game.

Where it's at

Asobu is in early development and built in the open. Vanilla Minecraft installs and launches today across the full version range, from the oldest releases to the current one. Mod loader support, a built-in mod browser and instance sharing are on the way.
