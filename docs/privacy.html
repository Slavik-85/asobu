Privacy

Asobu is a desktop application with no backend. It has no user accounts, collects no analytics, and transmits nothing about you to its developer. This page describes exactly what it stores and who it talks to.

Short version: we run no servers and receive no data from you at all. Everything the launcher knows stays on your own computer.

What we collect

Nothing. Asobu has no telemetry, no crash reporting service, no analytics and no update pings. The developer of Asobu receives no information about you, your machine, or your usage.

Microsoft sign-in

To play online you sign in with a Microsoft account. Asobu uses Microsoft's standard OAuth 2.0 authorization code flow with PKCE, opened in your own web browser.

  • Asobu never sees your password. You type it into Microsoft's own sign-in page. The launcher only ever receives a token afterwards.
  • Tokens are stored by the operating system. Your refresh token is held in Windows Credential Manager, encrypted with DPAPI. Asobu does not write it to a plain-text file or log.
  • Tokens are only sent to Microsoft and Mojang. They are exchanged with Xbox Live and Minecraft services to verify that you own Minecraft: Java Edition and to obtain your profile name and UUID, which the game requires to start.
  • Nothing is sent to us. There is no Asobu server involved at any point in sign-in.

Signing out through Asobu removes the cached token from Windows Credential Manager. You can also revoke Asobu's access at any time from your Microsoft account privacy settings.

Third parties Asobu contacts

Asobu makes network requests only to the services needed to sign in and to download the game:

  • Microsoft — sign-in and Xbox Live authentication.
  • Mojang / Minecraft services — verifying game ownership, and downloading Minecraft, its libraries, assets and the Java runtime.
  • Mod hosts — where you choose to download a mod, that download comes directly from its host.

Each of those services sees an ordinary download or sign-in request from your computer, exactly as the official Minecraft launcher would produce, and is governed by its own privacy policy.

What is stored on your computer

By default Asobu keeps its files in %APPDATA%\Asobu:

  • Instances — your worlds, mods, configuration and screenshots.
  • Cache — Minecraft versions, libraries, assets and Java runtimes, shared between instances.
  • Logs — the game's own output from each session, so crashes can be diagnosed. These stay on your disk and are never uploaded.
  • accounts.json — the display name and UUID of accounts you have added, so the launcher can list them. No tokens or passwords are stored in this file.
  • settings.json — your preferences, such as memory allocation and Java choice.

In portable mode this all lives in a data folder next to the executable instead. Deleting the folder removes everything Asobu has stored.

Children

Asobu does not knowingly collect information from anyone, of any age, because it collects no information at all. Microsoft account rules, including family and child-account restrictions, are enforced by Microsoft during sign-in.

Changes

If Asobu ever gains optional online features, this page will be updated before they ship, and anything that transmits data will be opt-in. The project is open source, so the behaviour described here can be verified in the code.
