Privacy

Asobu collects no analytics and has no tracking of any kind. This page describes exactly what the launcher stores, who it talks to, and what the planned online features will and will not involve.

Short version: as it ships today, Asobu has no backend at all — everything stays on your own computer. Friends and world sharing will need a server, and when they arrive they will be opt-in and will never carry your worlds or game files.

What we collect

Nothing. Asobu has no telemetry, no crash reporting service, no analytics and no update pings. The developer of Asobu receives no information about you, your machine, or your usage — and that will remain true whether or not you use the online features described below.

Microsoft sign-in

To play online you sign in with a Microsoft account. Asobu uses Microsoft's standard OAuth 2.0 authorization code flow with PKCE, opened in your own web browser.

  • Asobu never sees your password. You type it into Microsoft's own sign-in page. The launcher only ever receives a token afterwards.
  • Tokens are stored by the operating system. Your refresh token is held in Windows Credential Manager, encrypted with DPAPI. Asobu does not write it to a plain-text file or log.
  • Tokens are only sent to Microsoft and Mojang. They are exchanged with Xbox Live and Minecraft services to verify that you own Minecraft: Java Edition and to obtain your profile name and UUID, which the game requires to start.
  • Nothing is sent to us. There is no Asobu server involved at any point in sign-in.

Signing out through Asobu removes the cached token from Windows Credential Manager. You can also revoke Asobu's access at any time from your Microsoft account privacy settings.

Planned online features

These have not shipped yet. They are documented here in advance so there are no surprises, and this section will be updated to describe the shipped behaviour when they arrive. Both are opt-in — the launcher installs and plays Minecraft without them, and without ever contacting an Asobu server.

Friends

A friends list needs an identity, so Asobu will run a small service that knows who you are. Two deliberate choices about how it works:

  • Our server never receives your Microsoft or Minecraft tokens. Identity is proved using the same handshake Minecraft servers use: your launcher tells Mojang it is joining, and our server asks Mojang to confirm it. Mojang tells us your username and UUID — we never see, hold, or ask for a credential.
  • What it would store: your Minecraft username and UUID, the friends you add, and whether you are currently online. That is the whole point of a friends list, and it is all of it.

Opening a world to friends

Asobu will let you open a singleplayer world to friends. Importantly, your computer is the server — the world runs on your machine exactly as it does now.

  • Worlds never touch our infrastructure. We do not host, store, back up or have any access to your saves.
  • Our server only makes the introduction. It passes the connection details between the two PCs so they can talk directly, then gets out of the way.
  • Relay fallback. Some home networks refuse a direct connection. In that case the game traffic can be relayed through our server so the session still works. Relayed traffic is passed through, not inspected or stored.

Third parties Asobu contacts

Asobu makes network requests only to the services needed to sign in and to download the game:

  • Microsoft — sign-in and Xbox Live authentication.
  • Mojang / Minecraft services — verifying game ownership, and downloading Minecraft, its libraries, assets and the Java runtime.
  • Mod hosts — where you choose to download a mod, that download comes directly from its host.
  • Asobu's own service — only if you opt into friends or world sharing, as described above. Never otherwise.

Each of those services sees an ordinary download or sign-in request from your computer, exactly as the official Minecraft launcher would produce, and is governed by its own privacy policy.

What is stored on your computer

By default Asobu keeps its files in %APPDATA%\Asobu:

  • Instances — your worlds, mods, configuration and screenshots.
  • Cache — Minecraft versions, libraries, assets and Java runtimes, shared between instances.
  • Logs — the game's own output from each session, so crashes can be diagnosed. These stay on your disk and are never uploaded.
  • accounts.json — the display name and UUID of accounts you have added, so the launcher can list them. No tokens or passwords are stored in this file.
  • settings.json — your preferences, such as memory allocation and Java choice.

In portable mode this all lives in a data folder next to the executable instead. Deleting the folder removes everything Asobu has stored.

Children

Asobu does not knowingly collect information from anyone, of any age, because it collects no information at all. Microsoft account rules, including family and child-account restrictions, are enforced by Microsoft during sign-in.

Changes

This page is updated before a feature ships, not after. Anything that transmits data will be opt-in, and the project is open source, so everything described here can be checked against the code rather than taken on trust.
